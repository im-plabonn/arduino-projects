# Arduino Projects

This repository contains Arduino-based projects that use sensors like flame, ultrasonic, and other modules.

## Projects Included
- **Flame Sensor Alarm**: A fire detection system using a flame sensor and Arduino.
- **Ultrasonic Distance Meter**: A project that measures distance using the ultrasonic sensor.

### How to use?
Clone this repository and upload the `.ino` files to your Arduino board using the Arduino IDE.
